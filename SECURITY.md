# Security Policy

## Supported Versions

The latest version of AI Engineer Workbench is actively maintained.

Older versions may not receive security updates.

| Version | Supported |
|---------|-----------|
| Latest | ✅ |
| Older Releases | ❌ |

---

# Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public GitHub issue.

Instead:

- Contact the project maintainer privately.
- Provide a detailed description of the vulnerability.
- Include steps to reproduce the issue.
- If possible, suggest a potential fix.

Security reports will be acknowledged as quickly as possible.

---

# Scope

This policy applies to:

- Backend API
- Frontend application
- Authentication (future)
- Database interactions
- Deployment configuration
- Dependencies

---

# Best Practices

When contributing:

- Never commit secrets or API keys.
- Use environment variables for configuration.
- Keep dependencies up to date.
- Validate user input.
- Follow secure coding practices.

---

Thank you for helping keep AI Engineer Workbench secure.
